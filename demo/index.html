O que é uma GAN?

Muitos sistemas de aprendizado de máquina (*machine learning*) analisam algum tipo de entrada complexa (digamos, uma imagem) e produzem uma saída simples (um rótulo como "gato"). Em contraste, o objetivo de um modelo generativo é praticamente o oposto: receber uma pequena entrada—talvez alguns números aleatórios—e produzir uma saída complexa, como a imagem de um rosto de aparência realista. Uma rede adversária generativa (GAN) é um tipo especialmente eficaz de modelo generativo, introduzido há apenas alguns anos, que tem sido objeto de intenso interesse na comunidade de aprendizado de máquina.

Você pode se perguntar por que queremos um sistema que produza imagens realistas, ou simulações plausíveis de qualquer outro tipo de dado. Além do desafio intelectual intrínseco, isso se revela uma ferramenta surpreendentemente útil, com aplicações que vão desde a arte até o aprimoramento de imagens desfocadas.

Como funciona uma GAN?

A ideia de uma máquina "criar" imagens realistas do zero pode parecer mágica, mas as GANs usam dois truques principais para transformar um objetivo vago e aparentemente impossível em realidade.

A primeira ideia, que não é exclusiva das GANs, é usar a aleatoriedade como ingrediente. Em um nível básico, isso faz sentido: não seria muito interessante se você construísse um sistema que produzisse o mesmo rosto toda vez que fosse executado. Tão importante quanto isso, porém, é que pensar em termos de probabilidades também nos ajuda a traduzir o problema de gerar imagens para uma estrutura matemática natural. Obviamente, não queremos escolher imagens de forma uniformemente aleatória, pois isso produziria apenas ruído. Em vez disso, queremos que nosso sistema aprenda quais imagens têm probabilidade de serem rostos e quais não têm. Matematicamente, isso envolve modelar uma distribuição de probabilidade sobre imagens, ou seja, uma função que nos diz quais imagens têm probabilidade de serem rostos e quais não têm. Esse tipo de problema—modelar uma função em um espaço de alta dimensão—é exatamente o tipo de tarefa para a qual as redes neurais foram feitas.

A grande sacada que define uma GAN é configurar esse problema de modelagem como uma espécie de competição. É daí que vem a parte "adversária" do nome. A ideia principal é construir não uma, mas duas redes concorrentes: um gerador e um discriminador. O gerador tenta criar saídas sintéticas aleatórias (por exemplo, imagens de rostos), enquanto o discriminador tenta diferenciá-las de saídas reais (digamos, um banco de dados de celebridades). A esperança é que, à medida que as duas redes se enfrentam, ambas fiquem cada vez melhores—tendo como resultado final uma rede geradora que produz saídas realistas.

Resumindo: Redes adversárias generativas são redes neurais que aprendem a escolher amostras de uma distribuição especial (a parte "generativa" do nome), e fazem isso estabelecendo uma competição (daí "adversárias").

O que está acontecendo na visualização?

As GANs são estruturas complexas, e muita coisa acontece na visualização. Aqui estão as ideias básicas.

Primeiro, não estamos visualizando nada tão complexo quanto a geração de imagens realistas. Em vez disso, estamos mostrando uma GAN que aprende uma distribuição de pontos em apenas duas dimensões. Não há uma aplicação real para algo tão simples, mas é muito mais fácil mostrar a mecânica do sistema. Por um lado, distribuições de probabilidade no bom e velho espaço 2D (x,y) são muito mais fáceis de visualizar do que distribuições no espaço de imagens de alta resolução.

Escolha uma distribuição de dados.

No topo, você pode escolher uma distribuição de probabilidade para a GAN aprender, a qual visualizamos como um conjunto de amostras de dados. Assim que você escolhe uma, nós a mostramos em dois lugares: uma versão menor na visualização do grafo de visão geral do modelo à esquerda; e uma versão maior na visualização de distribuições em camadas à direita.

Figura 1. A distribuição de dados selecionada é mostrada em dois lugares.

Projetamos as duas visualizações para ajudar você a entender melhor como uma GAN funciona para gerar amostras realistas:
(1) O grafo de visão geral do modelo mostra a arquitetura de uma GAN, seus principais componentes e como eles estão conectados, além de visualizar os resultados produzidos pelos componentes;
(2) A visualização de distribuições em camadas sobrepõe as visualizações dos componentes do grafo de visão geral do modelo, para que você possa comparar mais facilmente as saídas dos componentes ao analisar o modelo.

Que comece o treinamento.

Para iniciar o treinamento do modelo GAN, clique no botão de reprodução () na barra de ferramentas. Além das amostras reais da distribuição escolhida, você também verá amostras falsas que são geradas pelo modelo. As posições das amostras falsas são atualizadas continuamente à medida que o treinamento avança. Uma GAN perfeita criará amostras falsas cuja distribuição é indistinguível daquela das amostras reais. Quando isso acontece, na visualização de distribuições em camadas, você verá as duas distribuições se sobreporem perfeitamente.

Figura 2. As posições das amostras falsas são atualizadas continuamente à medida que o treinamento avança. Então, as distribuições das amostras reais e falsas se sobrepõem perfeitamente.

Visualizando o gerador e o discriminador.

Lembre-se de que o gerador e o discriminador dentro de uma GAN estão travando uma pequena disputa, competindo entre si e atualizando iterativamente as amostras falsas para se tornarem mais semelhantes às reais. O GAN Lab visualiza as interações entre eles.

Gerador. Conforme descrito anteriormente, o gerador é uma função que transforma uma entrada aleatória em uma saída sintética. No GAN Lab, uma entrada aleatória é uma amostra 2D com um valor (x, y) (extraída de uma distribuição uniforme ou gaussiana), e a saída também é uma amostra 2D, mas mapeada em uma posição diferente, que é uma amostra falsa. Uma maneira de visualizar esse mapeamento é usando uma variedade (manifold) [Olah, 2014]. O espaço de entrada é representado como uma grade quadrada uniforme. À medida que a função mapeia posições no espaço de entrada para novas posições, se visualizarmos a saída, toda a grade, agora composta por quadriláteros irregulares, parecerá uma versão distorcida da grade regular original. A área (ou densidade) de cada célula (distorcida) mudou, e codificamos a densidade como opacidade; portanto, uma opacidade maior significa mais amostras em um espaço menor. Uma variedade muito refinada parecerá quase igual à visualização das amostras falsas. Esta visualização mostra como o gerador aprende uma função de mapeamento para fazer com que sua saída pareça semelhante à distribuição das amostras reais.

Figura 3. A transformação de dados do gerador é visualizada como uma variedade (manifold), que transforma o ruído de entrada (extrema esquerda) em amostras falsas (extrema direita).

Discriminador. À medida que o gerador cria amostras falsas, o discriminador, um classificador binário, tenta diferenciá-las das amostras reais. O GAN Lab visualiza sua fronteira de decisão como um mapa de calor (*heatmap*) 2D (semelhante ao TensorFlow Playground). As cores de fundo de uma célula da grade codificam os valores de confiança dos resultados do classificador. Verde mais escuro significa que as amostras naquela região têm maior probabilidade de serem reais; roxo mais escuro, maior probabilidade de serem falsas. À medida que uma GAN se aproxima do ótimo, todo o mapa de calor se tornará mais cinza de modo geral, sinalizando que o discriminador não consegue mais distinguir facilmente os exemplos falsos dos reais.

Figura 4. O desempenho do discriminador pode ser interpretado por meio de um mapa de calor 2D. Aqui, o discriminador está tendo um bom desempenho, já que a maioria das amostras reais encontra-se na região verde de sua superfície de classificação (e as amostras falsas na região roxa).

Entendendo a interação entre o gerador e o discriminador.

Em uma GAN, suas duas redes influenciam uma à outra à medida que se atualizam iterativamente. Um ótimo uso para o GAN Lab é empregar sua visualização para aprender como o gerador se atualiza incrementalmente para melhorar a si mesmo e gerar amostras falsas cada vez mais realistas. O gerador faz isso tentando enganar o discriminador. O valor de perda (*loss*) do gerador diminui quando o discriminador classifica amostras falsas como reais (ruim para o discriminador, mas bom para o gerador). O GAN Lab visualiza os gradientes (como linhas rosas) para as amostras falsas de forma que o gerador alcance seu objetivo.

Figura 5. As direções de movimento das amostras falsas são indicadas pelos gradientes do gerador (linhas rosas) com base nas localizações atuais dessas amostras e na superfície de classificação atual do discriminador (visualizada pelas cores de fundo).

Dessa forma, o gerador melhora gradualmente para produzir amostras ainda mais realistas. Assim que as amostras falsas são atualizadas, o discriminador será atualizado de acordo para ajustar sua fronteira de decisão, aguardando o próximo lote de amostras falsas que tentarão enganá-lo. Esse processo de atualização iterativa continua até que o discriminador não consiga mais diferenciar as amostras reais das falsas.

Como foi implementado?

O GAN Lab utiliza o TensorFlow.js, uma biblioteca de aprendizado profundo acelerada por GPU que roda no navegador. Tudo, desde o treinamento do modelo até a visualização, é implementado com JavaScript. Você só precisa de um navegador web como o Chrome para executar o GAN Lab. Nossa abordagem de implementação amplia significativamente o acesso das pessoas a ferramentas interativas para aprendizado profundo. O código-fonte está disponível no GitHub.

Quem desenvolveu o GAN Lab?

O GAN Lab foi criado por Minsuk Kahng, Nikhil Thorat, Polo Chau, Fernanda Viégas e Martin Wattenberg, sendo o resultado de uma colaboração de pesquisa entre a Georgia Tech e o Google Brain/PAIR. Agradecemos também a Shan Carter e Daniel Smilkov, à equipe Google Big Picture e ao Google People + AI Research (PAIR), além do Georgia Tech Visualization Lab pelo feedback.
